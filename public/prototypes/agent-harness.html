The domain team contributes

The plugin package, capability definitions, tool implementations, optional specialist behavior, and surface renderers. It owns the domain’s behavior and the contract for its inputs and results.

The harness provides

The session and agent coordination, capability registry, command palette, context and authorization, workbench lifecycle, and shared state channels. Personal settings shape discovery in the palette.
